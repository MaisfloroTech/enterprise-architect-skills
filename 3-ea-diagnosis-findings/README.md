# 🔍 3-ea-diagnosis-findings

*What you discovered in → findings you can act on without exposing anyone.*

## 🇪🇸 Español

Convierte lo que encontraste en el relevamiento en una tabla de hallazgos negativos clave, lista para trabajar en equipo:

- Por cada hallazgo: riesgo, oportunidad, sensibilidad, cómo se maneja y qué se hace si el riesgo se materializa.
- Lo delicado se conversa primero en privado, pidiendo el estado actual en vez de traer la mala noticia.
- Los planes de contingencia se atan al riesgo, no a la persona.
- Toda la sección se marca como revisión interna, y los ejecutivos solo ven las acciones neutras.

Sin culpables ni exposición. Nunca inventa hechos.

## 🇺🇸 English

Turns discovery findings into an internal-review table: risk, hidden opportunity, sensitivity, how each finding is handled (privately first when needed, by asking for the current state) and the contingency if the risk materialises, tied to the risk and not to the person. Executives only see the neutral actions. No blame, no made-up facts.
